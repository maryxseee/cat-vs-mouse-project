## Опис проєкту та ігрова механіка

**«Кіт і Миша: Графічна головоломка»** — це інтерактивна покрокова стратегічна гра, побудована на теорії графів. Головна мета полягає у протистоянні двох персонажів (гравця та штучного інтелекту) на динамічно згенерованому графі.

## Структура репозиторію

```text
├── xxx/
│   ├── assets/             # Папка з графічними ресурсами та шрифтами
│   ├── dist/catvsmouse/    # Готові зібрані файли для портативного запуску (.exe)
│   ├── ai_agent.py         # Логіка штучного інтелекту (Миша)
│   ├── config.py           # Глобальні конфігурації та константи
│   ├── draw_screen.py      # Допоміжні функції рендерингу екранів
│   ├── event_handler.py    # Обробка кліків миші та подій
│   ├── game_state.py       # Керування ігровими станами (GameManager)
│   ├── graph_gen.py        # Генератор графів на основі обмежень і BFS
│   ├── loss_screen.py      # Модуль екрана поразки
│   ├── main.py             # Головна точка входу в програму
│   ├── main.spec           # Конфігураційний файл PyInstaller
│   ├── menu_screen.py      # Модулі головного меню та меню паузи
│   ├── pixel_font.py       # Модуль кастомного піксельного шрифту
│   ├── renderer.py         # Рендеринг ігрового поля та персонажів
│   ├── ui_components.py    # Компоненти інтерфейсу (кнопки)
│   └── win_screen.py       # Модуль екрана перемоги
├── README.md               # Документація проєкту
└── catvsmouse.rar          # Портативний архів з готовою грою
